# 🌿 Атлас флоры Нижегородской области

Интерактивный справочник по **30 видам растений**, которые встречаются в лесах,
на лугах, болотах и рядом с жильём в Нижегородской области.

Статический сайт без сборки, зависимостей и интернета: достаточно открыть
`index.html` в браузере.

![Главная страница атласа](images/preview.jpg)

## Возможности

- **Поиск** по русскому и латинскому названию, семейству и местообитанию
  (регистр и «ё/е» не важны).
- **Фильтр по местообитанию**: лес, луг, болото и водоёмы, около жилья —
  с счётчиками видов.
- **Фильтр по месяцу цветения**: апрель–сентябрь.
- **Режим «Только редкие»** — виды из Красной книги Нижегородской области.
- **Карточка вида**: описание, семейство, высота, местообитания, сроки
  цветения и признаки — лекарственное, ядовитое, съедобное, медонос и т. д.
- **Адаптивная вёрстка**: 4 колонки на десктопе, 2 на телефоне; на мобильных
  карточка открывается нижней шторкой.
- **Доступность**: карточки открываются с клавиатуры (Enter/Space),
  модальное окно закрывается по Esc, учитывается `prefers-reduced-motion`.

![Карточка вида](images/preview-card.jpg)

## Запуск

Сайт работает прямо из файловой системы — просто откройте `index.html`
двойным кликом. Данные лежат в JS-файле, а не загружаются через `fetch`,
поэтому локальный сервер не обязателен.

Если удобнее через сервер:

```bash
cd "Project Flowers/atlas"
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Данные

Все виды описаны в массиве `PLANTS` в `data/plants.js`:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | string | уникальный идентификатор |
| `name` | string | русское название |
| `latin` | string | латинское название |
| `family` | string | семейство |
| `category` | string | `forest`, `meadow`, `water` или `urban` |
| `months` | number[] | месяцы цветения: 4 = апрель … 9 = сентябрь |
| `height` | string | высота растения |
| `habitat` | string | где встречается |
| `description` | string | описание вида |
| `features` | string[] | признаки: «Лекарственное», «Ядовитое», «Редкое» и др. |
| `red` | boolean | `true` — Красная книга Нижегородской области |
| `photo` | string | путь к фото (необязательно) |

Категории и их подписи в интерфейсе:

| Ключ | Подпись |
| --- | --- |
| `forest` | Лес |
| `meadow` | Луг |
| `water` | Болото и водоёмы |
| `urban` | Около жилья |

Сроки цветения форматируются автоматически: подряд идущие месяцы
схлопываются в диапазон («май–июнь»), остальные перечисляются через запятую.

## Как добавить растение

1. Положите фотографию в `images/` (необязательно).
2. Добавьте объект в массив `PLANTS` в `data/plants.js`:

```js
{
  id: "my-plant",
  name: "Название",
  latin: "Latin name",
  family: "Семейство",
  category: "meadow",          // forest | meadow | water | urban
  months: [5, 6],              // 4 = апрель … 9 = сентябрь
  height: "20–40 см",
  habitat: "Где встречается",
  description: "Описание вида.",
  features: ["Лекарственное"],
  red: false,                  // true — Красная книга Нижегородской области
  photo: "images/my-plant.jpg" // необязательно
}
```

3. Если фотография взята с Wikimedia Commons, добавьте автора и лицензию
   в `data/credits.js` — они появятся в карточке вида.
4. Обновите страницу — новый вид автоматически попадёт в поиск, фильтры,
   счётчики и статистику.

Новые признаки можно добавить в объект `FEATURE_CLASS` в `app.js` — им будет
назначен свой цвет бейджа (или нейтральный, если не указать).

## Фотографии и лицензии

- 28 материалов взяты с [Wikimedia Commons](https://commons.wikimedia.org/)

Автор, лицензия и ссылка на исходный файл показываются в карточке вида
(данные — в `data/credits.js`), полная таблица — в [`CREDITS.md`](CREDITS.md).
При повторном использовании сохраняйте атрибуцию и условия лицензий.

## Ограничения

- Сроки цветения и местообитания приведены **ориентировочно** для средней
  полосы: в разные годы они сдвигаются.
- Отметка «Редкое» соответствует Красной книге Нижегородской области, но
  списки переиздаются — перед сбором растений проверяйте актуальную редакцию.
- Атлас не является определителем: для точной идентификации нужны несколько
  признаков и, желательно, помощь специалиста.
- Фотографии подбирались автоматически по названию вида — при публикации
  стоит визуально сверить их с описанием.

## Технологии

- HTML, CSS, JavaScript — без фреймворков, сборки и внешних CDN;
- данные — обычный JS-массив, поэтому сайт полностью офлайн;
- адаптивная сетка на CSS Grid, модальное окно на нативном JS.
